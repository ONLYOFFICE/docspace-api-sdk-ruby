# DocspaceWebhooksSdk::UserPayload

## Properties

| Name | Type | Description | Notes |
| ---- | ---- | ----------- | ----- |
| **id** | **String** | The ID of the user the event is about; &#x60;GET api/2.0/people/{userid}&#x60; returns the full profile by it. | [optional] |
| **display_name** | **String** | The user&#39;s full name in the name order set for the portal, HTML-encoded. | [optional] |
| **first_name** | **String** | The user&#39;s first name as entered in the profile. | [optional] |
| **last_name** | **String** | The user&#39;s last name as entered in the profile. | [optional] |
| **user_name** | **String** | The unique login name of the user, made from the local part of their email address when the account is created. Absent when the subscription&#39;s creator is a User or a Guest, who may not see the contacts of other users, unless this user is that creator. | [optional] |
| **email** | **String** | The email address the user signs in with and receives notifications at. Absent when the subscription&#39;s creator is a User or a Guest, who may not see the contacts of other users, unless this user is that creator. | [optional] |
| **contacts** | [**Array&lt;ContactPayload&gt;**](ContactPayload.md) | The additional contacts from the user&#39;s profile, such as extra phone numbers, emails and social links. Absent when the profile has none, and when the subscription&#39;s creator is a User or a Guest, who may not see the contacts of other users, unless this user is that creator. | [optional] |
| **status** | **Integer** | Whether the account is active or disabled. A disabled user cannot sign in; &#x60;terminated&#x60; says since when. Flags of &#x60;EmployeeStatus&#x60;: 1 &#x3D; Active, 2 &#x3D; Terminated, 4 &#x3D; Pending, 5 &#x3D; Default, 7 &#x3D; All. | [optional] |
| **activation_status** | **Integer** | Whether the user has confirmed their email address. The &#x60;AutoGenerated&#x60; flag is never set here. Flags of &#x60;EmployeeActivationStatus&#x60;: 0 &#x3D; NotActivated, 1 &#x3D; Activated, 2 &#x3D; Pending, 4 &#x3D; AutoGenerated. | [optional] |
| **terminated** | **Time** | When the account was disabled, in UTC. Absent while the account is active. | [optional] |
| **department** | **String** | The comma-separated names of the groups the user belongs to, as plain text rather than HTML-encoded; empty when the user is in no group. Omitted when the subscription owner is a &#x60;User&#x60; or a &#x60;Guest&#x60; and the event is about someone else. | [optional] |
| **groups** | [**Array&lt;GroupSummaryPayload&gt;**](GroupSummaryPayload.md) | The groups the user belongs to; absent when the user is in no group. Omitted as well when the subscription owner is a &#x60;User&#x60; or a &#x60;Guest&#x60; and the event is about someone else. | [optional] |
| **location** | **String** | The location the user entered in the profile; empty or absent when not filled in. | [optional] |
| **notes** | **String** | The free-text notes on the user&#39;s profile; empty or absent when not filled in. | [optional] |
| **is_admin** | **Boolean** | True when the user is a DocSpace admin, who manages the portal settings and every room. False for the portal owner, who has every admin right as well: read &#x60;isOwner&#x60; for that user. | [optional] |
| **is_room_admin** | **Boolean** | True when the user&#39;s type is Room admin, who may create rooms and manage the rooms they own. | [optional] |
| **is_owner** | **Boolean** | True for the portal owner, the single account that owns the portal. | [optional] |
| **is_visitor** | **Boolean** | True when the user&#39;s type is Guest, an external account that works only in the rooms it was invited to. | [optional] |
| **is_collaborator** | **Boolean** | True when the user&#39;s type is User, who works in the rooms they are invited to but cannot create rooms. | [optional] |
| **is_ldap** | **Boolean** | True when the account is synchronized from an LDAP directory, which then owns its name and email. | [optional] |
| **is_sso** | **Boolean** | True when the account came from single sign-on and signs in through the identity provider. | [optional] |
| **list_admin_modules** | **Array&lt;String&gt;** | The IDs of the product modules the user administers. Absent when the user administers none. | [optional] |
| **culture_name** | **String** | The interface language the user chose, as a culture code. Absent when the user follows the portal&#39;s language. | [optional] |
| **mobile_phone** | **String** | The mobile phone number from the user&#39;s profile; absent when none is set, and when the subscription&#39;s creator is a User or a Guest, who may not see the contacts of other users, unless this user is that creator. | [optional] |
| **mobile_phone_activation_status** | **Integer** | Whether the mobile phone number has been confirmed, as SMS sign-in confirmation requires. Flags of &#x60;MobilePhoneActivationStatus&#x60;: 0 &#x3D; NotActivated, 1 &#x3D; Activated. | [optional] |
| **quota_limit** | **Integer** | How much storage the user may use, in bytes; -1 when the limit is switched off for this user. Absent when user quotas are turned off on the portal or the portal keeps no storage statistics, and for any subscription owner other than a &#x60;DocSpaceAdmin&#x60; or the user themselves. | [optional] |
| **used_space** | **Float** | How much storage the user&#39;s files take, in bytes. Absent when the portal keeps no storage statistics, and for any subscription owner other than a &#x60;DocSpaceAdmin&#x60; or the user themselves. | [optional] |
| **is_custom_quota** | **Boolean** | True when &#x60;quotaLimit&#x60; was set for this user individually, false when it is the portal&#39;s default user quota. Absent whenever &#x60;quotaLimit&#x60; is absent because quotas are off or statistics are not kept, and for any subscription owner other than a &#x60;DocSpaceAdmin&#x60; or the user themselves. | [optional] |
| **created_by** | [**UserSummaryPayload**](UserSummaryPayload.md) |  | [optional] |
| **registration_date** | **Time** | When the account was created, in UTC. | [optional] |
| **has_avatar** | **Boolean** | False when the user has not uploaded a photo; the avatar URLs then point to the default picture. | [optional] |
| **avatar** | **String** | The absolute URL of the 82x82 avatar, with a hash query parameter that changes when the profile does. | [optional] |
| **avatar_original** | **String** | The absolute URL of the original avatar, with the same hash parameter. | [optional] |
| **avatar_max** | **String** | The absolute URL of the 200x200 avatar, with the same hash parameter. | [optional] |
| **avatar_medium** | **String** | The absolute URL of the 48x48 avatar, with the same hash parameter. | [optional] |
| **avatar_small** | **String** | The absolute URL of the 32x32 avatar, with the same hash parameter. | [optional] |
| **profile_url** | **String** | The absolute link to the user in the portal&#39;s list of people, or of guests for a guest; today it is a search of that list by the user&#39;s email address. Absent when the subscription&#39;s creator is a User or a Guest, who may not see the contacts of other users, unless this user is that creator. | [optional] |
